Local-first agent

Nyx Ichos

A multi-agent AI assistant that runs on your own machine. Your conversations, memory, and files stay local — online providers are an option, never a requirement.

Option 1

Use in browser

The full workspace — Strands HUD, chat, agents, skills, dynamic tabs — running in this tab.

  • Nothing to install
  • Machine control is not included
  • Needs a backend to talk to
Open the web app
Option 2

Download the app

The complete build. Runs entirely on your machine, works offline with a local model, and includes the capabilities the hosted version deliberately omits.

  • Full machine control, permission-gated
  • Works offline via Ollama
  • Your data never leaves the device
Get the local build
Why the two builds differ. The hosted version has machine control and self-modification compiled out — not switched off, but absent. An endpoint that reads a filesystem or takes screenshots is a remote-access tool once it is on the open internet, however carefully it is gated. Those capabilities are safe on hardware you own, so they live in the local build only.

Running the local build

git clone <your-repo> nyx-ichos
cd nyx-ichos
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

# start the backend
.venv\Scripts\python.exe -m uvicorn server:app --port 8000

# claim the owner account (sets your password; stored only as a salted hash)
.venv\Scripts\python.exe admin_setup.py claim you@example.com

Then open http://localhost:5173 for the workspace, or use the terminal client with python cli.py. No API key is required — a local Ollama model works offline. Adding a key for Gemini, OpenAI, or others enables online providers and cross-model collaboration.
