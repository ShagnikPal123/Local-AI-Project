Set up Nyx Ichos

Thanks for testing. This page takes you from download to your first conversation, one step at a time. The first setup takes about ten minutes; after that, Nyx is one click.

Before you start

No account and no admin password — and nothing to type to get it running.

  • A Windows 10 or Windows 11 PC (64-bit).
  • About 1 GB of free space for Nyx, Python and its packages.
  • An internet connection for the first setup (it downloads Python if you don't have it, and about 80 MB of packages).
  • A Google or NVIDIA account if you want a free AI key — or Ollama to run fully offline.

Nyx runs on your own PC. Your chats, notes, memory and API keys stay on your computer. Nothing is sent to the person who invited you.

Install

Four steps, done once.

  1. Download the newest beta

    Looking up the newest beta release…

    Download Release page 
    
          
    
          
    
            The file is called NyxIchos-beta-<version>.zip. If someone sent it to you
            directly, skip to step 3. If the button above doesn't appear, open the releases
            page and download the .zip from the newest release whose name starts with
            beta-. Save it somewhere you'll find it, like Downloads.
          
    
        
    2. 

        
  2. 
          
    Check it's the real file (recommended)
    
          
    
            Every beta release comes with a release.json that lists the zip's fingerprint
            (its sha256). To compare: open the Start menu, type PowerShell, open it, and paste this
            (change the file name if yours is different):
          
    
          
    
            Get-FileHash "$HOME\Downloads\NyxIchos-beta-*.zip" -Algorithm SHA256 | Format-List
            
          
    
          
    
            The Hash it prints must match the sha256 in release.json on the
            release page (capital letters don't matter). If they don't match, don't open the zip — download it again.
          
    
        
    3. 

        
  3. 
          
    Unblock and extract
    
          
      
            
    • Right-click the zip → Properties. If there's an Unblock box at the bottom, tick it and press
              OK. This stops Windows warning you about every file inside.
      • 
            
    • Right-click the zip again → Extract All… → choose a folder you'll keep, for example
              Documents\NyxIchos → Extract.
      • 
          
    
          
    Don't run Nyx from inside the zip. Windows lets you open a zip like a folder, but
            nothing inside can be installed from there. Always extract first.
    
        
    4. 

        
  4. 
          
    Double-click Start Nyx
    
          
    Open the folder you extracted and double-click Start Nyx (it may show as Start Nyx.bat). A black window opens and does the setup for you:
    
          
      
            
    • [1/3] Python — if you don't have Python 3.11 or newer, it installs Python 3.13 just for your
              account (no admin needed).
      • 
            
    • [2/3] Packages — it downloads about 80 MB of Nyx's packages. This is the slow part: a few minutes.
      • 
            
    • [3/3] Shortcuts — it puts a Nyx Ichos icon on your desktop and in the Start menu, turns on
              start-with-Windows, and opens Nyx in your browser.
      • 
          
    
          
    If Windows shows “Windows protected your PC”, choose More info → Run anyway.
            Start Nyx is a plain text script — right-click it → Edit to read exactly what it does. Nyx is run by
            Python's own signed program, not an unknown .exe.
    
        
    5. 
      

    


    

      
First run

      
Nyx opens at localhost:8000 in your browser.

      
    
        
  1. 
          
    Give Nyx a brain: add a free AI key
    
          
    Nyx needs at least one AI model to think with. The easiest free one:
    
          
      
            
    • Go to Google AI Studio, sign in, and press
              Create API key. Copy it.
      • 
            
    • In Nyx, open the Keys & Models tab, find Gemini, paste the key and save.
      • 
          
    
          
    Other free options: an NVIDIA key from build.nvidia.com
            (same tab, NVIDIA), or install Ollama to run models on your
            own PC with no key at all.
    
          
    Your key is a password. Keep it in Nyx only — never paste it into a chat, a bug
            report or a message to anyone.
    
        
    2. 
        
  2. 
          
    Say hello
    
          
    Open the Nyx tab and type something — “what can you do?” is a good start. You'll see what it's working
            on while it answers.
    
        
    3. 
      

    


    

      
Every day after that

      
Nyx starts with Windows and waits in the tray near the clock. To open it, any of these works:

      

        
    
          
  • Double-click Nyx Ichos on your desktop.
    • 
          
  • Right-click the Nyx icon near the clock → Open Nyx. The same menu has Restart engine and Quit Nyx.
    • 
          
  • Press this button (your browser asks the first time — choose Open):
    • 
        

        
Launch Nyx

        
Nothing happened? Nyx isn't set up on this PC
          yet — go back to Install and double-click Start Nyx once.

      

    


    

      
Getting updates

      
New beta versions are reviewed before they're published, and Nyx checks the file before it installs anything.

      
    
        
  1. 
          
    Open Settings → Updates
    
          
    Leave the Release channel on Beta and press Check for a release.
    
        
    2. 
        
  2. 
          
    Download it
    
          
    If there's a new version, press Download. Nyx refuses the file unless its fingerprint matches the
            published one, and tells you when it does.
    
        
    3. 
        
  3. 
          
    Restart to install
    
          
    Press Restart to Install…. Nyx stops for about 20 seconds, installs the update and comes back. Your chats,
            keys, memory and notes are never touched. If the new version misbehaves, Roll Back the Last Update… in the
            same place puts the previous files back.

What to test, and how to report it

      
Use Nyx for real things. These are the parts that most need a fresh pair of eyes:

      

        
    
          
  • Chat — ask hard questions, ask it to search the web, ask it to make a chart.
    • 
          
  • Game Studio — describe a game and let Nyx design it, then play it in 2D and 3D.
    • 
          
  • Notes — paste lecture notes and make a quiz or flashcards.
    • 
          
  • Code — open a folder, start a small project from scratch, ask for a change and review it.
    • 
          
  • Sub-agents — make a helper with its own chat and give it a task.
    • 
        

      

      

        Found a problem? Open an issue on
        GitHub (or message the person who invited you) with:
      

      

        
    
          
  • Your Nyx version — it's at the top of Settings → Updates.
    • 
          
  • What you did, what you expected, and what happened instead.
    • 
          
  • A screenshot if it's something you can see. Crop out any API keys.
    • 
        

      

    


    

      
If something goes wrong

      
Most problems are one of these.


      

        The black Start Nyx window closed straight away, or said something failed
        

          
Run it again — a slow connection sometimes breaks the package download half-way, and the second run carries on.

          
If it still fails, install Python yourself from python.org
            (tick Add python.exe to PATH during setup), then double-click Start Nyx again.

        

      

      

        The browser says it can't reach localhost:8000
        

          
Nyx takes up to 30 seconds to start. Wait, then refresh the page.

          
Still nothing? Right-click the Nyx icon near the clock → Restart engine. No icon at all? Double-click
            Nyx Ichos on your desktop.

        

      

      

        Nyx answers “no model is available” or something about a key
        

          
Open Keys & Models and check your key is saved (it shows the last four characters). A free key has a
            daily limit — if you hit it, add a second free key or a different provider and Nyx will use whichever works.

        

      

      

        Something else is already using port 8000
        

          
Another program is using the same address. Quit it, or restart your PC, then open Nyx again.

        

      

      

        Setup got stuck or broken and I want to redo it
        

          
Open the Nyx folder, then in the address bar type cmd and press Enter. In the window
            that opens, paste this and press Enter — it re-runs setup from the start without deleting your chats:

          

            "Start Nyx.bat" --repair
            
          

        

      

      

        How do I uninstall it?
        

          
Right-click the Nyx icon near the clock → Quit Nyx. Then open the Nyx folder, type cmd
            in the address bar, press Enter, and run this to remove the shortcuts and start-with-Windows:

          

            .venv\Scripts\python.exe setup_nyx.py --uninstall
            
          

          
Finally delete the Nyx folder. Your chats and keys live inside it, so deleting it removes them too — copy anything
            you want to keep first.
