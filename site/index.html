Local-first agent

Nyx Ichos

A multi-agent AI assistant that runs on your own machine. Your conversations, memory, and files stay local — online providers are an option, never a requirement.

Checking your machine…
Open Local Workspace (localhost:8000) → Open Web Workspace (/app/) →

Double-click start.bat on your machine to start the local engine, then open the workspace above.

Get it running

Three steps, once. After that it is a single double-click.

  1. Get the code

    Clone the repository, or download and unzip it.

    git clone <your-repo> nyx-ichos

  2. Download the launcher

    One file. Put it in the project folder — it installs anything missing the first time you run it.

    Saves start.bat. It is already in the repo too.

  3. Run it

    Double-click start.bat. That is it — it opens your browser when ready.

    start.bat

    Prefer to type it yourself? .venv\Scripts\python.exe -m uvicorn server:app --port 8000

The button at the top turns on by itself once the engine answers — no refresh needed.

Why there is no cloud version. Nyx runs on your hardware on purpose. An endpoint that reads your filesystem or takes screenshots becomes a remote-access tool the moment it is on the open internet, however carefully it is gated — so machine control and self-modification are compiled out of any hosted build, not merely switched off. This page hands you over to the engine on your own computer, which is why it is private, and why it needs the app installed first.

What it does

StrandsA live map of how your ideas, agents, and memories actually connect.
Agent teamNamed agents with their own goals, and a master that manages them.
SkillsDescribe a capability; it writes the skill and applies it automatically.
Dynamic tabsAsk for a tab and it builds one. Say "make it green" and it does.
Hardware safetyReads real GPU telemetry and throttles before the machine suffers.
Power modesLow to Max, or Auto — bounded by what your machine can actually take.

No API key needed. A local Ollama model runs offline. Adding a key for Gemini, OpenAI, Groq or DeepSeek turns on online providers and cross-model collaboration.
