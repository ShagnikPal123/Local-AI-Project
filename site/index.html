Install

Running in three steps

Once, a couple of minutes. After that Nyx is one click away — and it starts with Windows, waiting by the clock.

  1. Download

    Get NyxIchos-Windows.zip. It is the whole app — no installer, nothing else to fetch by hand.

    Download

  2. Extract

    Right-click the zip and choose Extract All. Windows can’t run Nyx from inside a zip, so this step matters.

  3. Start Nyx

    Open the folder and double-click Start Nyx. The first time, it installs Python if you need it, adds a Nyx Ichos icon to your desktop and opens Nyx in your browser.

Already set up? Launch Nyx from here. The first time, your browser asks whether to open Nyx — choose Open.

Launch Nyx

Nothing opened? Nyx isn’t set up on this PC yet — download it and run Start Nyx once. After that, this button works.

If Windows stops it SmartScreen, Python, a slow first run

“Windows protected your PC.” Nyx isn’t signed by a paid certificate yet, so Windows asks first. Choose More info, then Run anyway. Every line it runs is in the source on GitHub.

Python didn’t install. Start Nyx uses Windows’ own installer (winget). If that’s missing, install Python 3.11 or newer from python.org, then double-click Start Nyx again.

The first run seems slow. It downloads about 80 MB of packages once. Later starts take seconds.

Something else? Double-click Start Nyx again — it picks up where it stopped, and prints the first error if one happens.

Run from source For developers

Clone the repository, then double-click Start Nyx.bat in the folder — the same one-time setup runs, and the desktop icon points at your checkout.

git clone https://github.com/ShagnikPal123/Local-AI-Project.git nyx-ichos

Prefer to do it by hand? From the project folder:

python -m venv .venv .venv\Scripts\python.exe -m pip install -r requirements.txt cd frontend\nyx-pulse && npm install && npm run build && cd ..\.. .venv\Scripts\python.exe -m uvicorn server:app --port 8000

Then open localhost:8000. The engine serves the app itself — one process, no second server.

What’s inside

One assistant, many rooms

Every part is a tab in the app, and they share one memory — so what you tell Nyx in one place, it knows in the others.

Second Brain

A living map of everything Nyx reads, says and learns. Search it, or fly through it.

Big Kahuna

Its main brain. It sends each request to the model that does it best, and trains a small model of its own on your PC.

Agents & Office Space

Named agents with their own jobs. Hand a big task to an office of them and watch it split up.

Voice

Talk hands-free. It answers out loud, keeps listening while it speaks, and never hears itself.

Screen Share

Show it a window and it points to what to click. It acts only when you say so.

Research & Notes

Cited research reports, and study tools that turn your slides into notes and quizzes.

Code & Build

Open a folder and edit it together, or design 3D-printable parts and the circuits inside them.

Trading Practice

Paper trading with simulated money, fees and market hours. Real money only if you connect it.

Privacy

Yours, on your PC

An assistant that can see your screen and open your files belongs on your computer, not on someone’s server.

Local

Your data stays home

Chats, memory, notes and files are kept on your computer. Nothing is uploaded to run Nyx.

Optional

Keys are up to you

With Ollama it runs offline with no key at all. Add Gemini, Groq, NVIDIA or others for online models when you want them.

On purpose

No cloud copy

Machine control and self-editing are left out of any hosted build entirely — not switched off, absent — so they only ever exist on your own PC.
