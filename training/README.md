# Training Data Workspace

This folder is intentionally reserved for future personal training and learning artifacts for Nyx Pulse.

## Contents

- `personal_training_notes.md` — private notes about user preferences, style, working patterns, and recurring tasks.
- `online_results_training_log.md` — a structured log for storing useful outputs from online model runs when that path is enabled later.

## Purpose

Keep this data separate from app code so the assistant can grow in a controlled way without mixing training materials into runtime logic.

## Recommended rules

- Keep this data local and explicit.
- Store only what is useful for personalization and quality improvements.
- Label each item with source, date, and context.
- Avoid automatically importing raw online data without review.
- Prefer small, structured examples over noisy bulk dumps.
